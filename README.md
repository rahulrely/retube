# 🎬 Retube Frontend

> A sleek and scalable video management frontend for Retube, built with **Next.js** , **Tailwind CSS** , **ShadcnUI** , **AceternityUI** , and **Cloudinary**.

## 🌐 Live Demo

🔗 [retube.vercel.live](https://retube.live)

## 📦 Features

- 🎥 **Video Upload Interface** with drag-and-drop and preview
- 🔐 **OAuth Integration** with Google for authentication
- 🎛️ **Role-based Views** (Admin, User)
- ☁️ **Cloudinary Integration** for fast video delivery
- 🚀 **Responsive UI** powered by Tailwind CSS , Shadcn and Aceternity
- 🔁 **Session Management** with cookies and token-based authentication
- 🧩 Modular and maintainable component structure

## 🛠️ Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Cloud**: Cloudinary
- **Auth**: Google OAuth
- **State Management**: React Hooks + Context
- **Forms**: React Hook Form + Zod
- **HTTP**: Axios
